# Загвар → ажил, тоо хэмжээ → нэгж үнэ

Шинэ барилгын дэлгэц дээр загвар сонгож үүсгэхэд загварын ажлуудыг лавлахын
тогтвортой `work_type_id`-аар үүсгэнэ. Загваргүй үүсгэлт өмнөх шиг зөвхөн
байршлуудтай, ажилгүй байна.

Локал 3 загварыг шинэ лавлахтай `cpms:sync-catalog-designs` командаар холбосон:

| Загвар | Холбогдсон ажил | Үүсэх ажлын мөр |
|---|---:|---:|
| 16 давхар, 9 айл | 269 | 3531 |
| 12 давхар, 6 айл | 269 | 2315 |
| 4 давхар үйлчилгээ | 258 | 671 |

Дутуу нэгжтэй, байршил тодруулаагүй ажлыг загварт таамгаар нэмэхгүй.
Зоорь, тодорхой давхар, 2–16 гэх хүрээг мөр үүсгэх болон урьдчилан тооцохдоо
ижил дүрмээр шүүнэ. Айлгүй загварт айлын түвшний ажил орохгүй.

Шинэ холбоосын `qty_per_location` хоосон. Эх Excel-ийн 1 хэмжээ, 100 үнийг
бодит тоо болгож хуулдаггүй. Барилга үүссэний дараа «Тоо хэмжээ нөхөх» хэсэгт
бодит хэмжээг оруулна. Дахин синк хийхэд өмнө бөглөсөн загварын хэмжээг хадгална.

## Ажлын хөлсний үнийн импорт

Барилга сонгоод «Үнийн файл татах» товчоор тухайн барилгад үүссэн ажлуудтай
Excel гаргана. Ажлын код C, нэгж I, одоогийн хэмжээ AC, нэгж үнэ AD баганад байна.
Нэр өөр байсан ч кодоор танина. Код, нэгжийг хэвээр үлдээж AD-д үнэ бөглөнө.

- Хоосон үнэ алгасагдана; 0 бол илэрхий үнэгүй үнэ.
- Ижил ажлын нэгж үнэ тухайн барилгын тэр ажлын бүх байршилд үйлчилнэ.
- Код танигдахгүй, барилгад ажил үүсээгүй, нэгж зөрсөн, үнэ сөрөг/тоон биш,
  эсвэл нэг ажлын код давхардсан бол алдаатай файл батлагдахгүй.
- Preview нь ажлын мэдээлэл өөрчлөхгүй. Apply нь зөвхөн `budget_unit_price`-г
  шинэчилнэ; ажлын id, нэр, тоо хэмжээ, огноо, инженер, гүйцэтгэл, зураг хэвээр.
- Шинэ ажил үүсгэхгүй, төсөвт ороогүй ажлыг устгахгүй. `replace/update` горимууд
  вэб API дээр зөвшөөрөгдөхгүй; зөвхөн `prices` горим хэрэглэнэ.
- Материалын төсөв нь тусдаа импортын урсгал хэвээр. Үнийн татах файлд ажлын
  хөлсний хуудас болон тайлбар орно; материалын зохиомол жишээ нэмэхгүй.

## Ажиллуулах

Backend эх код ба Laravel хуулбар хоёуланд синк хийсэн. Шинэ schema migration
шаардлагагүй. Лавлахын байршлыг шийдсэний дараа:

```sh
php artisan cpms:resolve-catalog-locations
php artisan cpms:sync-catalog-designs
php artisan queue:work --sleep=1 --tries=1 --timeout=600
```

Загвар буулгах нь queue дээр ажиллана. Локал worker-ийг энэ өөрчлөлтөөр эхлүүлсэн;
лог нь `cpms-api-app/storage/logs/catalog-template-worker.log`-д байна. Backend
дахин эхлэхэд worker-ийг мөн ажиллуулах шаардлагатай.

`cpms:import-quantities` хуучин нэртэй CLI нь мөн одоо зөвхөн нэгж үнэ шинэчилнэ.
`--mode=prices`; `--prune` болон хуучин replace/update горимыг хориглоно.

## Шалгалт

`CatalogTemplatePriceWorkflowTest` нь HTTP-ээр загвартай барилга үүсгэх,
зөв давхруудад мөр үүсэх, preview өөрчлөлтгүй байх, apply зөвхөн үнэ солих,
гүйцэтгэл болон оноолт үлдэх, давхар батлалт хориглох, буруу код/нэгж/үнэ,
давхардсан код татгалзах, Excel экспортын кодыг шалгана.

Лавлах, устгал, байршил, хоосон барилгын холбогдох тестүүдтэй нийлээд 29 тест
амжилттай. Mock импортын урсгал, TypeScript, өөрчилсөн файлуудын ESLint шалгасан.
Хуучин mock-ийн барилгын demo загварууд regression fixture хэвээр; бодит шинэ
лавлахын загвар үүсгэлтийг Laravel HTTP интеграцийн тестээр шалгана.
