# Ажлын төлөвлөсөн ба бодит хугацаа

Барилга → Ажлын төлөвлөгөө → ажлаа хайх → Хугацаа төлөвлөх.
Эхлэх, дуусах огноог нэг ажилд эсвэл ижил ажлын сонгосон байршлуудад багцаар хадгална.
Багц сонголт шинэ ажил үүсгэхгүй. Байгаа ажлуудын огноог өөрчилнө.
Гараар төлөвлөсөн ажлын огноог багцаар дахин өөрчлөхөд тусгай чагт сонгоно.
Батлагдсан гүйцэтгэлтэй ажлын огноог өөрчлөхгүй; сунгалтын урсгал ашиглана.
Гүйцэтгэл эхэлсний дараа дахин төлөвлөхөд анхны амлалт (baseline) хадгалагдана.

Автомат хуваарь нь Ажлын төлөвлөгөө хэсгийн «Нэмэлт · Анхны автомат хуваарь»-т байна.
Гараар төлөвлөсөн, явц мэдээлсэн, бодитоор эхэлсэн болон батлагдсан ажлуудыг алгасана.
Сунгалт батлагдсан ажлуудыг мөн автомат хуваариас хамгаална.

Гүйцэтгэл мэдээлэхдээ бодит эхэлсэн огноог баталгаажуулна.
Бүх тоо хэмжээний гүйцэтгэлийг мэдээлэх үед «Энэ ажил бодитоор бүрэн дууссан» чагтаар дууссан огноог бүртгэнэ.
Ажлын дэлгэрэнгүй → Бодит огноо бүртгэх хэсгээс огноогоо засаж болно.
Бодит дуусалт нь хяналтын батлалт биш; эцэслэн баталсан огноо тусдаа хадгалагдана.
Татгалзсан хэмжээнээс шалтгаалан ажил дахин хийх шаардлагатай бол бодит дууссан огноо цэвэрлэгдэж, дараагийн гүйцэтгэлээр шинэчлэгдэнэ.

Бодит үргэлжилсэн хугацаа, хоцорч дууссан хоног нь хуанлийн өдрөөр тооцогдоно.
Хоцролтыг бодит дууссан огноо болон одоогийн төлөвлөсөн дуусах огноотой харьцуулна.
Өмнөх хоцролтын/сунгалтын үзүүлэлт, анхны амлалтын огноо тусдаа хэвээр.
Барилгын тайлан болон Excel тайланд бодит эхэлсэн/дууссан огноотой, хоцорч дууссан ажлын тоо нэмэгдсэн.

## Шинэчлэх

Frontend, backend кодыг шинэчлээд backend дээр `php artisan migrate --force` ажиллуулна.
Migration хуучин төлөвлөсөн огноог бодит огноо болгон хувиргахгүй.
Хуучин гүйцэтгэлийн анхны огноог зөвхөн санал болгож, хэрэглэгч баталгаажуулна.
Хуучин бүрэн батлагдсан ажлын баталсан огноог шалгалтын түүхээс авна.
